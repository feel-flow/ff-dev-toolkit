# ACE 旧テーブル形式エントリの allowlist
#
# ここに列挙した ID は `| フィールド | 値 |` ヘッダ + Insight/Context/Action ブロックの
# 旧形式のまま残すことを許可する（読み取り互換）。載っていない ID が旧形式なら
# `scripts/ace/check-entry-format.ts` が exit 1 でブロックする。
#
# このファイルが存在しない場合は「例外なし」= strict として扱われる（旧形式は全て赤）。
# 新規プロジェクトは空のまま置くか、ファイル自体を作らなくてよい。
#
# 書式:
# - 1 行 1 ID（`ACE-41-1` のように大文字の ID をそのまま書く）
# - `#` で始まる行と空行は無視される
#
# 運用:
# - **新規追記でこのファイルに ID を足さない**。新規はコンパクト正準フォーマットで書く
#   （allowlist は既存エントリの互換維持のためのものであり、新規追記の抜け道ではない）
# - `/ace-refine` の圧縮でエントリを正準化したら、その ID をこのファイルから削除する
# - アーカイブ・統合で live から消えた ID も削除する
# - 削除し忘れてもブロックはされないが、ゲートが警告を出す（「正準化済みなのに
#   allowlist に残っている」「live に存在しない」の 2 種）
#
# 既存プロジェクトへ導入するときは、まず allowlist 無しで実行して検出された ID を
# そのまま書き出すと現状を緑にできる（例）:
#
#   npx --yes tsx scripts/ace/check-entry-format.ts docs/08-knowledge/PLAYBOOK.md
#
# 導入後は旧形式をカテゴリ単位で `/ace-refine` 正準化し、この一覧を減らしていく。
