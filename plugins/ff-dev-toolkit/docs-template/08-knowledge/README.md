# Knowledge Base Index

このディレクトリは、開発を通じて蓄積した知見・記録の置き場です。ファイルによって対象読者・更新タイミングが異なるため、新規に何かを書くときは下表で置き場を選んでください。

## 使い分け表

| --------------------------------- | --------------------- | ------------------------------------------------------------------ | ------------------------------------------------------ |
| `PLAYBOOK.md`（+ `playbook/`）    | AI（+ 人間）           | ACE 由来の構造化知見（append-only エントリ）                       | マージ後の `/ace-curate`。定期整理は `/ace-refine`      |

## 証跡文書（`YYYY-MM-DD-<slug>-evidence.md`）

正本（[MASTER.md](../MASTER.md) やコア7文書、`CLAUDE.md` 等）に実測の詳細を書き足すと、レビューのたびに数字・単位・スコープの整合を取り直す面が増え、前巡の修正が次の指摘を生んで収束しなくなる。この配置規範の SSOT は [MASTER.md の「実測の記録先」](../MASTER.md#実測の記録先)。

- 正本へ残す・写すのは **判断手順・判断に直結する境界値・測り直しコマンド・証跡へのリンク** だけ
- 実体数・版の一覧・時刻表・スコープ差の注記のような時間で腐る記述は、本ディレクトリの日付付き証跡文書へ置く
- ファイル名は `YYYY-MM-DD-<slug>-evidence.md`（例: `2026-09-12-plugin-suite-count-evidence.md`）。日付は**初回作成日で固定し、追記しても改名しない**（改名すると参照リンクが壊れる。更新の履歴は後述のとおり本文の行として残す）
- 数字を引き直すときは証跡文書に書いたコマンドを回し直し、結果を**新しい行として追記**する（古い行は消さない。実測の履歴として残す）
