# 終了コードガードの入力書き換え

Claude Code の PreToolUse は `updatedInput` で入力全体を置換し、`additionalContext` でエージェントへ通知できる（[公式仕様](https://code.claude.com/docs/en/hooks#pretooluse-decision-control)）。本ガードは通常の権限判定を維持するため、自動 allow を追加しない。

対応を確認する環境は `CLAUDECODE=1` と `CLAUDE_PROJECT_DIR` を持ち、入力に `model` が無く grok root が無い PreToolUse。未対応・未確認ホストでは従来の抜け道付き deny を維持する。環境変数は能力を見分ける補助であり、認証境界ではない。

一意な単一コマンドと `tail` / `head` の件数指定、直後の終了コード表示だけを対象にする。展開・制御構文・複数パイプ・関数内・その他のリダイレクトは書き換えない。元コマンドを評価して分解せず、構文検査だけを行う。変換後は一時ログへ標準出力と標準エラーを受けて終了コードを保存し、指定フィルタで表示、ログを削除して同じコードを返す。実行本文は引用した `bash -c` の引数へ渡し、producerは元の標準入力を継承する。producer全体が終了してから表示するため、ストリームを途中で打ち切る動作にはならない。

`run-bash-hooks.sh` は全tool_inputフィールドと通知を保持し、一意な提案だけを全ガードへ再投入する。再拒否・競合・command以外の変更・再書き換えは停止する。元のdeny/askも維持する。ホストへの伝達と変換後コマンドの終了コードはstdin fixtureで検証し、実セッションでの入力置換は未実測として報告する。

zsh の一覧scalarの停止は、同じ呼び出しの直前にある standalone 代入の空白値またはコマンド置換を根拠とする。値やコマンド置換は評価しない。引用・配列・前置代入・別スコープは新しい停止対象外、値不明は従来の警告を維持する。単一引数は引用し、複数引数は配列、xargs、bashの引用付きheredocを選ぶ。
