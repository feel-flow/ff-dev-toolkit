# 終了コードガードの入力書き換え

Claude Code の PreToolUse は `updatedInput` で入力全体を置換し、`additionalContext` でエージェントへ通知できる（[公式仕様](https://code.claude.com/docs/en/hooks#pretooluse-decision-control)）。本ガードは通常の権限判定を維持するため、自動 allow を追加しない。

対応を確認する環境は `CLAUDECODE=1` と `CLAUDE_PROJECT_DIR` を持ち、入力に `model` が無く grok root が無い PreToolUse。未対応・未確認ホストでは従来の抜け道付き deny を維持する。環境変数は能力を見分ける補助であり、認証境界ではない。

書き換えを提案する終了コードの扱いは次の 2 つ。

- 件数指定の `tail` / `head` を使い、直後に終了コードを表示する単一のパイプまたはセミコロン区切りの並び。各区間の標準出力と標準エラーを一時ログへ受け、指定フィルタで表示する。最初に非 0 になった区間の終了コードを返し、全区間が成功したときは 0 を返す。
- 単一の `producer | tail -N && next`。パイプから標準出力を EOF まで一時ログへ受ける。`2>&1` が明示された場合は標準エラーも合流させる。左側・ログへの書き込み・`tail` がすべて成功したときだけ後続を実行する。後続はホストの権限判定に渡るように `bash -c` の外へ置き、その終了コードを返す。ログへの書き込み自体が失敗した場合は、その終了コードを返して停止する。

展開・追加の制御構文・関数・サブシェル・背景起動・一意でない区間・その他のリダイレクトを含む入力は書き換えの対象外。候補の生成時は構文検査だけを行う。ログを処理する本文は引用した `bash -c` の引数へ渡し、左側のコマンドは元の標準入力を継承する。一時ログは終了時に削除する。

`run-bash-hooks.sh` は全 `tool_input` フィールドと通知を保持し、一意な提案を全ガードへ再投入する。再拒否・再検査未完了・競合・`command` 以外の変更・再書き換えは停止する。元の deny/ask も維持する。ホストへの伝達と変換後コマンドの終了コードは stdin fixture で検証し、実セッションでの入力置換は未実測として報告する。

zsh の一覧scalarの停止は、同じ呼び出しの直前にある standalone 代入の空白値またはコマンド置換を根拠とする。値やコマンド置換は評価しない。引用・配列・前置代入・別スコープは新しい停止対象外、値不明は従来の警告を維持する。単一引数は引用し、複数引数は配列、xargs、bashの引用付きheredocを選ぶ。
