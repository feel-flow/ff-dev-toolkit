# GitHub file input: precheck / linking / cleanup

`bash plugins/ff-dev-toolkit/tests/github-input-precheck/verify.sh` runs offline with disposable Git repositories and an allowlisted tool PATH. The file lane rejects every gh invocation. The optional arguments are an absolute plugin root, case manifest, and evidence directory; the default run removes temporary evidence.

The eight golden cases retain the original six cases and add two replied, nonempty review threads. One includes deleted PR/comment authors and nullable path / line / originalLine. Their raw null values are preserved. PR and thread bodies exceed 140 KB; explicit Japanese merge text includes quotes and trailing newlines. Each gh/file pair uses the same repository, Git state, head and gate record. Five scalar lines and the entire MERGE_COMMAND_BEGIN..END block must each occur exactly once and compare byte-for-byte, including line endings. Both branch deletion modes and fork behavior are represented.

The negative cases distinguish absent required fields from legal empty arrays, false and null. They cover initial/final head identity, separate thread cursors and checks attempts, missing/unreadable/bad/duplicate index entries, wrong repository/PR, incomplete MCP field mapping, unanswered threads and gate freshness. Cleanup executes only with --dry-run and preserves the existing OID/open-list guard PARTIAL results. Linking either verifies complete membership or emits the exact PLAN with rc 2; a static fixture is not an external write.

An explicit evidence directory stores original raw JSON, stdout, stderr, return codes, NUL-delimited argv, rejected gh-call logs and the original temporary input-root mapping. Index/body bytes are copied without rewriting paths or normalizing output. The suite includes extraction miss controls against a previously proven complete ready output and requires nonzero complete ready coverage. The verify.sh header records separately measured absent/empty/unreadable/source-mutation probes.

The synthetic MCP raw fixture demonstrates that REST counts do not supply missing GraphQL closing references, commit arrays, check rollups or files. It must stop with rc 2. No live MCP acquisition, external write or fresh post-write read-back was performed by this suite. Host operation contracts are in [merge-gate](../../skills/close-issue/references/merge-gate.md#github-file-input).
