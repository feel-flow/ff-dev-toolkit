# DECISIONS（決定ログ節の外にある比較表を無視する fixture）

ADR 本文中の代替案比較表が `| ADR-N |` 形式の行を持っていても、決定ログ表の走査対象は
`## 決定ログ` 節に限定されることを固定する（節を抜けた比較表の番号まで拾うと、決定ログ表に
無い番号を余分に table-only として名指ししてしまう）。

## 決定ログ

| ADR番号 | タイトル   |
| ------- | ---------- |
| ADR-001 | 最初の決定 |

## ADR-001: 最初の決定

決定本文。
