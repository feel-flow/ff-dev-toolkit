# DECISIONS（整合している fixture）

検出器の positive control。フェンス内の雛形・例示行を名簿へ入れないことも同時に固定する
（ADR-900 を拾うと決定ログ表に無い番号として非 0 になる。見出し側・表側の双方を固定する）。

## 決定記録テンプレート

```markdown
## ADR-XXX: [タイトル]

## ADR-900: フェンス内の例示は名簿へ入れない
```

## 決定ログ

| ADR番号 | タイトル     |
| ------- | ------------ |
| ADR-001 | 最初の決定   |
| ADR-002 | 二つ目の決定 |

```markdown
| ADR-900 | フェンス内の表例示は決定ログ表へ数えない |
```

## ADR-001: 最初の決定

決定本文。

決定本文。
